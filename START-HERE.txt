ASAR — ЛОКАЛЬНАЯ ДЕМОНСТРАЦИЯ

Распакуйте архив полностью. Сохраните папки .runtime, .local-ai и .data.

WINDOWS 10 / 11 x64
1. Откройте Start-Windows.cmd.
2. В браузере перейдите на http://localhost:3000.
3. Логины и пароли: откройте Accounts-Windows.cmd.
4. Не закрывайте окно запуска во время показа. Остановка — Ctrl+C.

Если не хватает MSVCP140.dll или VCRUNTIME140*.dll:
один раз запустите .runtime\windows-x64\vc_redist.x64.exe,
затем повторите Start-Windows.cmd. Возможен запрос прав администратора.
Комплект содержит Node.js для Windows x64; npm-пакеты для показа не нужны.

LINUX x64
Нужен установленный Node.js 24.11 или новее.
В папке проекта: bash Start-Linux.sh
Адрес: http://localhost:3000
Учётные записи: node scripts/accounts.mjs

Локальная модель может запускаться около минуты и отвечать десятки секунд.
Если модель недоступна, работает явно обозначенный поиск по базе знаний.
Заявки, вложения и обучение сохраняются в .data. Пароли не публикуйте.
Перед защитой проверьте комплект на настоящем Windows-компьютере.
