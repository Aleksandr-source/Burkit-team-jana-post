JANAMEN — ЗАПУСК ДЛЯ ПОКАЗА

Из репозитория, в терминале папки проекта:
  npm ci
  npm run build
  npm run ai:setup
  npm start

Нужен Node.js 24.11+ и npm. Установка ИИ один раз скачивает модель
Qwen3-0.6B Q4_K_M и подходящий движок llama.cpp для Windows/Linux x64.
При следующем запуске достаточно npm start.

Адрес в браузере: http://localhost:3000
Данные для входа: npm run accounts (во втором терминале).
Оставьте окно сервера открытым. Остановка — Ctrl+C.

Если готовые dist и .local-ai уже подготовлены для этой системы,
можно открыть Start-Windows.cmd или выполнить bash Start-Linux.sh.
Для Windows нужен Node.js в PATH или комплектный
.runtime\windows-x64\node.exe. Эти файлы не входят в Git-репозиторий.
При ошибке отсутствующей DLL установите Visual C++ Redistributable x64.

Состояние демонстрации хранится в .data. Переносите её целиком после
остановки приложения, если нужны прежние заявки, прогресс и пароли.
Без .data создаётся новая демонстрация. Не публикуйте пароли.

Полная инструкция и ограничения: README.md.
Лицензии: llama.cpp — MIT; Qwen3-0.6B — Apache-2.0.
