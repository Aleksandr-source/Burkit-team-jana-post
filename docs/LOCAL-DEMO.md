# Локальная демонстрация JanaMen

Это готовое веб-приложение: небольшой сервер работает на вашем компьютере, а интерфейс открывается в браузере. Внешний хостинг и AI API для демонстрации не нужны. Готовая папка содержит собранный интерфейс `dist`; устанавливать npm-пакеты перед показом не требуется.

## Перенос на другой компьютер

Распакуйте архив целиком в отдельную папку. Не запускайте файлы прямо внутри ZIP. Переносите также папки с точкой в начале имени: `.runtime`, `.local-ai`, `.data`, если они входят в комплект. В `.data` находятся демонстрационные сотрудники, заявки, результаты обучения и вложения. База копии работает отдельно от исходного проекта.

Не открывайте `dist/index.html` двойным щелчком: для авторизации и данных должен работать сервер.

## Windows 10 / 11 x64

1. Дважды нажмите **Start-Windows.cmd** в корне распакованной папки.
2. Дождитесь сообщения сервера с адресом. Обычно это **http://localhost:3000** — откройте его в Chrome, Edge или другом современном браузере.
3. Оставьте окно запуска открытым, пока показываете приложение.
4. Откройте **Accounts-Windows.cmd**, чтобы увидеть тестовые email и пароли.
5. После показа остановите сервер сочетанием **Ctrl+C** в окне запуска. Если Windows попросит подтвердить завершение командного файла, подтвердите его.

Запуск предпочитает комплектный `.runtime/windows-x64/node.exe`. Если его нет, используется Node.js из PATH; нужна версия **24.11 или новее**. Этот комплект предназначен для Windows x64. На Windows ARM и других архитектурах комплектные бинарники не заявляются совместимыми.

Для локального AI нужны системные библиотеки **Microsoft Visual C++ Redistributable x64**. Если появится ошибка об отсутствии `MSVCP140.dll`, `VCRUNTIME140.dll` или `VCRUNTIME140_1.dll`, один раз запустите комплектный официальный установщик **`.runtime/windows-x64/vc_redist.x64.exe`**. Может потребоваться разрешение администратора. После установки снова откройте **Start-Windows.cmd**. Установка npm-пакетов для готового приложения не нужна, но системные библиотеки могут потребовать этой отдельной установки.

Windows-файлы подготовлены для переноса, но их запуск необходимо проверить на реальном Windows-компьютере до защиты: Linux-проверка не заменяет такую проверку.

## Linux x64

Нужен Node.js **24.11 или новее** из системы:

```bash
bash Start-Linux.sh
```

Далее откройте **http://localhost:3000**. Для просмотра учётных записей из корня проекта:

```bash
node scripts/accounts.mjs
```

Готовый Linux-движок AI рассчитан на x64 и совместимые glibc-библиотеки. На другой архитектуре или несовместимом дистрибутиве потребуется отдельная сборка движка. `node_modules` не нужны для готового показа; они устанавливаются через `npm ci` только для разработки и пересборки.

## Локальный ассистент

При наличии подходящего комплектного движка и весов модель запускается вместе с приложением. Первый запуск может занять около минуты; интерфейс HR при этом доступен. Ответы на слабом CPU могут занимать десятки секунд. Скорость зависит от процессора, оперативной памяти и текущей нагрузки.

Проверьте индикатор в разделе «JanaMen AI». **Локальная модель** означает, что доступен нейросетевой режим. **Поиск по базе знаний** означает извлечение разрешённых выдержек: это честно обозначенный резервный режим, если движок ещё загружается, занят или недоступен. Источники показываются в обоих режимах. Сотрудники и кадровые правила в базе демонстрационные.

Для офлайн-показа нужны заранее включённые в комплект веса и подходящий движок. Файлы GGUF переносимы между системами; исполняемые файлы движка и их библиотеки должны соответствовать ОС и архитектуре. Установщик `scripts/setup-ai.mjs` поддерживает Linux и Windows x64; перед показом готовой копии его запускать не требуется. Повторная загрузка модели и движка требует интернета. На Windows для установки из исходной папки используются `curl.exe` и PowerShell; сборка движка из исходников через `--build` остаётся Linux-вариантом.

## Тестовые аккаунты и сохранение

Пользуйтесь **Accounts-Windows.cmd** или файлом `.data/demo-accounts.txt`. Если база в комплект не включена, сотрудники и новый пароль создаются при первом запуске; после этого повторно откройте список аккаунтов. Файл содержит пароли только демонстрационной среды и не предназначен для публичного репозитория.

Изменения заявок и результаты обучения сохраняются в `.data`. Не удаляйте эту папку, если хотите продолжить показ позже. Для разных ролей используйте отдельные профили браузера, разные браузеры или приватное окно. Обычные вкладки одного браузера используют один аккаунт. Настройки оформления и язык сохраняются в текущем браузере.

## Если не запускается

- **Нет `dist/index.html`:** архив распакован не полностью либо в него не включена готовая сборка. Нужна вся папка проекта.
- **Node.js не найден:** проверьте наличие комплектного `node.exe` на Windows; на Linux установите Node.js 24.11+.
- **Windows сообщает об отсутствующей DLL:** выполните `.runtime/windows-x64/vc_redist.x64.exe`, затем повторите запуск. Это официальный Microsoft Visual C++ Redistributable x64; установка может потребовать права администратора.
- **Адрес уже занят:** остановите ранее запущенный JanaMen через Ctrl+C и повторите запуск. Две копии не могут одновременно использовать один порт 3000.
- **Интерфейс открылся, модель недоступна:** дождитесь загрузки и проверьте сообщения терминала. HR-сценарий и поиск по базе знаний продолжают работать.
- **Нет списка аккаунтов:** сначала запустите приложение, затем снова откройте Accounts-Windows.cmd.

Не закрывайте терминал во время демонстрации и не публикуйте `.env`, `.data`, пароли или локальные служебные ключи. Внешняя публикация и реальные интеграции с 1С/Documentolog в этот локальный запуск не входят.
